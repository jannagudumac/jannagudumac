## Projet RNCP — Music Wall

Application web full-stack réalisée dans le cadre de ma certification RNCP **Concepteur Développeur d’Applications**.

**Music Wall** permet aux utilisateurs de créer des espaces d'écoute personnalisés, d'organiser albums et morceaux en sections et de partager leurs murs avec d'autres utilisateurs.

### Architecture et fonctionnalités

- Frontend en **Angular 19 / TypeScript / RxJS**
- Backend REST en **Java / Spring Boot**
- Persistance avec **PostgreSQL / JPA / Hibernate**
- Authentification stateless avec **JWT**, mots de passe hashés avec **BCrypt**
- Gestion des utilisateurs, murs, membres, sections et contenus
- Recherche dans un catalogue musical local
- Tests backend avec **JUnit, Mockito et MockMvc**
- Environnement local avec **Docker / Docker Compose / Nginx**
- Déploiement avec **Netlify + Render + PostgreSQL**

[🌐 Démo live](https://music-wall.netlify.app) &nbsp;&nbsp; [💻 Code source](https://github.com/jannagudumac/music-wall)
